## Additional technical source

[W3C Understanding SC 1.4.3: Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), checked 4 October 2026, supports the normal/large-text contrast thresholds. The contrast tool now compares the bold-text boundary against the exact conversion of 14 points to CSS pixels, avoiding premature decimal rounding. This is an accessibility source, not a Google AdSense requirement.

[Hostinger privacy policy](https://www.hostinger.com/legal/privacy-policy), checked 4 October 2026, is linked as the confirmed hosting provider's own policy. It does not establish this account's log-retention settings; the owner explicitly left those unverified. The owner's supplied `/privacy` address is an alias for UtilityPilot's own policy, not Hostinger's policy.

## Boundaries of the assessment

Follow-up checked 4 October 2026: [Google's crawler reference](https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers#google-inspectiontool) distinguishes Google-InspectionTool from other crawlers. [Search Console URL Inspection](https://support.google.com/webmasters/answer/9012289?hl=en) is not independent proof of a Mediapartners-Google request. Owner-reported Search Console success must not be relabeled as verified AdSense crawler access.

- About/Contact quality is an observable transparency issue. We do not represent a named set of legal pages as a universal Google checklist or invent a requirement for a street address or professional credentials.
- `build:release` enforces this project's factual configuration requirements; it is not a Google-mandated command or an automated eligibility decision.
- No arbitrary minimum traffic, page age, page count or word count was imposed.
- No invented publisher ID, ads.txt seller entry, business identity, author biography, testimonials or consent records were added.
- Hosting challenges are separate from application code. A robots.txt allowance does not guarantee access through a CDN security check.
